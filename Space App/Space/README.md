# Space — каркас приложения

SwiftUI-приложение для iPhone, iPad и Mac. Читает папку с Markdown-заметками (хранилище Obsidian подходит как есть) и показывает её как космос.

| В хранилище | В Space |
|---|---|
| папка верхнего уровня | вселенная |
| папка второго уровня | созвездие |
| файл `.md` | звезда |
| `[[ссылка]]` | связь |

Заметки из корня хранилища попадают во вселенную «Входящие», заметки прямо в папке вселенной — в созвездие «Свободные звёзды». Скрытые папки (`.obsidian`, `.trash`, `.git`) пропускаются.

## Что нужно

- Mac с **Xcode 26** или новее: в нём есть SDK iOS 26 / macOS 26 с Liquid Glass (`.glassEffect`, `.buttonStyle(.glass)`).
- Для запуска на своём iPhone — бесплатный Apple ID в Xcode. Для App Store и подписок — Apple Developer Program.

## Как открыть проект

### Вариант А — через XcodeGen (быстрее)

```bash
brew install xcodegen
cd Space
xcodegen generate
open Space.xcodeproj
```

### Вариант Б — вручную

1. Xcode → File → New → Project → **Multiplatform → App**. Название `Space`, интерфейс SwiftUI.
2. Удали созданные Xcode файлы `SpaceApp.swift` и `ContentView.swift`.
3. Перетащи в проект папку `Space/` из этого архива (Copy items if needed, Create groups).
4. В настройках таргета: Minimum Deployments — iOS 26.0 и macOS 26.0.
5. Signing & Capabilities → **App Sandbox** (Mac) → File Access → *User Selected File: Read/Write*.

Дальше выбери схему `Space` и устройство (My Mac или симулятор iPhone) и нажми ⌘R.

## Первый запуск

Нажми «Открыть хранилище» и выбери **копию** хранилища Obsidian. Приложение запомнит папку и откроет её при следующем запуске. Правки в редакторе сохраняются в `.md` файлы через 0,7 секунды после того, как перестаёшь печатать, — поэтому сначала тестируй на копии.

## Что уже работает

- Открытие папки и сохранение доступа к ней между запусками (security-scoped bookmark).
- Разбор `[[ссылок]]` (включая `[[Заметка|алиас]]`, `[[Заметка#заголовок]]`, пути) и `#тегов`; вложения `![[…]]` не считаются связями.
- Боковая панель: вселенные → созвездия → заметки.
- Карта космоса на `Canvas`:
  - три уровня одной карты: мультивселенная → вселенная → звезда в фокусе;
  - перелёт камеры, затем звёзды выстраиваются на орбиты 1–4 (созвездие → остальное созвездие → эта вселенная → другие вселенные), пустые орбиты не рисуются;
  - звёзды плавают, при наведении замирают и подсвечивают свои связи;
  - перетаскивание карты, щипок для масштаба, поиск звезды, «Путь» из последних звёзд;
  - клик по центральной звезде открывает заметку.
- Редактор заметки с автосохранением и инспектор «Орбита»: входящие связи, ссылки отсюда, теги.
- Liquid Glass: верхняя панель, поиск, «Путь», панель фокуса, кнопки.

## Структура

```
Space/
  App/SpaceApp.swift          точка входа
  Vault/                      чтение и запись хранилища
    Note.swift                модель заметки
    MarkdownParser.swift      [[ссылки]] и #теги
    VaultScanner.swift        обход папки
    BookmarkStore.swift       доступ к папке между запусками
    VaultStore.swift          состояние приложения
  Cosmos/
    Cosmos.swift              граф: вселенные, созвездия, связи
    WorldLayout.swift         координаты звёзд и раскладка орбит
  Map/
    MapModel.swift            камера, перелёты, плавание, наведение
    MapRenderer.swift         отрисовка кадра
    CosmosMapView.swift       жесты и попадания
    MapOverlays.swift         стеклянные панели карты
  Views/                      онбординг, боковая панель, редактор
  Theme/                      цвета, фон-космос
```

## Следующие шаги

1. Редактор на TextKit 2: подсветка Markdown, автодополнение `[[`.
2. Перетаскивание звёзд по орбитам (как в макете) и сохранение позиций.
3. «Большой взрыв» по датам создания файлов.
4. Отслеживание изменений в папке (NSFilePresenter), чтобы правки из Obsidian подхватывались сразу.
5. Space Pro на StoreKit 2: темы, автосборка вселенных (Foundation Models / NaturalLanguage).
